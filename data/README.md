# Dataset

This project uses the **Real Estate Valuation** dataset from the UCI Machine Learning Repository.

## Source

UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/477/real+estate+valuation+data+set

## Dataset Information

- Records: 414
- Input Features: 6
- Task: Regression
- Target: House Price of Unit Area

## Features

1. Transaction Date
2. House Age
3. Distance to the Nearest MRT Station
4. Number of Convenience Stores
5. Latitude
6. Longitude

The original dataset is not included in this repository.
